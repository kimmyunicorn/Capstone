About SeaStar

SeaStar is a student-designed Remotely Operated Vehicle (ROV) created for a senior capstone project. The system is built to explore underwater environments while collecting environmental data and water samples.

Project Mission

The goal of SeaStar is to support environmental monitoring by collecting water samples and measuring water conditions such as dissolved oxygen. This data helps researchers better understand aquatic ecosystem health and changes over time.

System Overview

SeaStar integrates mechanical design, embedded systems, and software into a single underwater platform. The robot is operated using a web-based user interface and a handheld controller. ROS 2 manages communication between sensors, control nodes, and the user interface, enabling real-time control and data monitoring.

Technologies Used

• ROS 2 for system architecture and communication
• Python for control and data logging
• Web-based UI for operator control and telemetry
• Custom mechanical design and underwater hardware

SeaStar is part of an interdisciplinary effort to combine robotics, software, and environmental engineering into a real-world system.
